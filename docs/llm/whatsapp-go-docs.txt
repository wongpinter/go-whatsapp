## OVERVIEW
The go-whatsapp library is a comprehensive Go package for integrating with WhatsApp Business Cloud API. It provides type-safe interfaces for message sending, webhook handling, business management, and WhatsApp Flows with framework-agnostic HTTP server abstraction.

## CORE_FEATURES
- Message sending (text, media, templates, interactive)
- Webhook event handling with signature verification
- Business Management API for template management
- WhatsApp Flows builder and data exchange
- HTTP server abstraction (Gin, Echo, standard HTTP)
- HTTP client management with connection pooling
- Comprehensive error handling and rate limiting
- Security features (signature verification, token encryption)

## QUICK_START_PATTERNS

### Pattern: Send Text Message
```go
import "github.com/wongpinter/go-whatsapp/cloudapi"

client := cloudapi.NewClient("PHONE_NUMBER_ID", "ACCESS_TOKEN")
resp, err := client.SendText(context.Background(), "+1234567890", "Hello World!")
```

### Pattern: Setup Webhook Handler
```go
import "github.com/wongpinter/go-whatsapp/webhook"

handler := webhook.NewHandler("VERIFY_TOKEN", "APP_SECRET", logger)
handler.SetMessageHandler(&MyHandler{})
http.HandleFunc("/webhook", handler.ServeHTTP)
```

### Pattern: Build WhatsApp Flow
```go
import "github.com/wongpinter/go-whatsapp/flows"

flow := flows.NewFlowBuilder().
    SetVersion("3.0").
    AddScreen("screen1").
        SetTitle("Contact Form").
        AddTextInput("name", "Full Name").SetRequired(true).Done().
        AddEmailInput("email", "Email").SetRequired(true).Done().
        SetTerminal(true).
        Done().
    Build()
```

### Pattern: Create Message Template
```go
import "github.com/wongpinter/go-whatsapp/bm"

template := bm.NewTemplateBuilder().
    SetName("order_confirmation").
    SetCategory(bm.CategoryUtility).
    SetLanguage("en_US").
    AddComponent(bm.NewBodyComponent().SetText("Order {{1}} confirmed")).
    Build()
```

## COMMON_ERROR_CODES
- 130429: Rate limit exceeded (retry with exponential backoff)
- 80007: API call limit exceeded (retry with exponential backoff)
- 131000: Generic user error (do not retry)
- 131005: Message undeliverable (do not retry)
- 131014: Template not found (check template name/ID)
- 131016: Template paused (template needs approval)

### Retry with Exponential Backoff
```go
func sendWithRetry(client *cloudapi.Client, to, message string) error {
    maxRetries := 3
    baseDelay := time.Second
    
    for i := 0; i < maxRetries; i++ {
        resp, err := client.SendText(context.Background(), to, message)
        if err == nil {
            return nil
        }
        
        if apiErr, ok := err.(*cloudapi.APIError); ok && apiErr.Code == 130429 {
            delay := baseDelay * time.Duration(1<<i)
            time.Sleep(delay)
            continue
        }
        
        return err
    }
    
    return errors.New("max retries exceeded")
}
```

## TROUBLESHOOTING_GUIDE

### Issue: Webhook signature verification fails
- Check app secret configuration
- Verify payload reading (don't read body twice)
- Ensure correct signature header format

### Issue: Rate limit exceeded
- Implement exponential backoff retry
- Check your API tier limits
- Use built-in rate limiting features

### Issue: Template not approved
- Review template content for policy compliance
- Check template category selection
- Ensure proper parameter formatting

### Issue: Flow token validation fails
- Verify private key is correctly loaded
- Check token expiration time
- Ensure proper token generation

## VALIDATION_RULES

### PHONE_NUMBER_FORMAT
- Must include country code (e.g., +1234567890)
- No spaces, dashes, or special characters
- Length: 10-15 digits after country code

### TEMPLATE_NAME_RULES
- Lowercase letters, numbers, underscores only
- No spaces or special characters
- Maximum 512 characters
- Must be unique within business account

### FLOW_VERSION_RULES
- Supported versions: "3.0"
- Must be specified for all Flows
- Version determines available components

### MESSAGE_LENGTH_LIMITS
- Text messages: 4096 characters
- Template parameters: 1024 characters each
- Button text: 20 characters
- List item title: 24 characters
